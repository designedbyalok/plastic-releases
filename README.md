# Plastic for Mac — releases

Downloads and the update feed for **Plastic for Mac**, the visual editor whose designs are real HTML and CSS. The app's source is private; this repository only hosts releases.

- **Download:** get the latest DMG from [useplastic.app/download](https://useplastic.app/download) or from [Releases](https://github.com/designedbyalok/plastic-releases/releases). Plastic for Mac is for Apple silicon Macs.
- **Updates:** installed apps update themselves from the signed `mac-update-feed` release. Please don't rely on its URL directly.
- **Connecting agents:** see [AGENTS.md](AGENTS.md) for connecting Claude Code, Codex, Cursor and other agents over MCP.
- **What's new:** [useplastic.app/changelog](https://useplastic.app/changelog).
